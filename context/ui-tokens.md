# UI Design Tokens

## Palette Tokens (SwiftUI & Human Interface Guidelines)
- **Synapse Accent Purple:** `Color(red: 0.45, green: 0.35, blue: 0.95)`
- **Synapse Electric Cyan:** `Color(red: 0.15, green: 0.78, blue: 0.98)`
- **Synapse Coral Alert:** `Color(red: 1.00, green: 0.42, blue: 0.38)`
- **Synapse Success Emerald:** `Color(red: 0.18, green: 0.80, blue: 0.44)`
- **Background Primary:** `Color(uiColor: .systemBackground)` / `Color(nsColor: .windowBackgroundColor)`
- **Card Background:** `Color(uiColor: .secondarySystemBackground).opacity(0.8)` with glassmorphism blur
- **Border Subtle:** `Color.primary.opacity(0.12)`
- **Typography Font:** System Rounded / Inter / San Francisco Pro with Monospace code blocks.
