# UI Styling Rules & Design System

## Layout & Component Rules
- **SwiftUI Native:** Use modern declarative views, NavigationStack, ScrollView, and LazyVStack.
- **Glassmorphism & Vibrancy:** Material backgrounds (`.ultraThinMaterial` / `.thinMaterial`) for node execution cards and approval sheets.
- **Micro-Animations:** Use `.spring(response: 0.35, dampingFraction: 0.85)` for node state transitions, streaming token arrivals, and graph branching.
- **Accessibility First:** Dynamic Type support, VoiceOver accessibility labels on graph nodes, high-contrast borders for active execution paths.
