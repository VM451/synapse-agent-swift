# UI Component Registry (Living Document)

## Registered Components
- `AgentChatView`: Full-featured conversational agent interface with streaming bubble responses, tool execution indicators, and attachment previews.
- `TimeTravelInspectorView`: Developer time-travel scrubber showing chronological checkpoints, node execution graph visualizer, and state diff views.
- `InterruptApprovalBanner`: Human-in-the-loop interactive approval card displaying pending action, parameters, risks, and Approve / Reject / Edit buttons.
- `NodeExecutionGraphView`: Live visual topology graph illustrating active node, completed edges, and branching conditions.
